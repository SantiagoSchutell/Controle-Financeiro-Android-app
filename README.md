# Finance APP

Esse é um aplicativo de controlar seus gastos e contas

*Utilizado padrão MVVM

## 🚀 Tecnologias Utilizadas
* **Linguagens**: Kotlin.
* **Backend BaaS**: Firebase (Auth, Firestore, Storage).
* **UI**: Material Design components.
* 

## ✨ Funcionalidades Principais
* Autenticação segura via Firebase Auth.
* Adição e remoção de contas
* Adição de contas de investimentos, onde pode adicionar ativos e valor em cada ativo.
